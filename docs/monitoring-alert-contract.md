# 监控中心告警边界

监控中心是系统公共提醒的唯一入口。进入监控中心左侧“触发记录”、菜单未读徽标和公共实时提醒流的事件，必须由 `MonitorRuleEngine` 命中一条已启用的监控规则后产生。

## 允许的来源

公共监控记录只接受以下来源：

- `strategy`
- `signal`
- `price`
- `market`
- `ladder`
- `sector`

规则命中后由行情服务统一完成去重、写入 `data/user_data/alerts.jsonl`、SSE 推送和可选 Webhook。没有规则时，监控中心不会因为行情、盘口、打板池或持仓风控的内部状态变化产生提醒。

## 打板专区

短线猎手仍可保留自己的候选、盘口和订单时间线，但不再注册独立行情/盘口监听器，也不再向公共 `alerts.jsonl`、监控中心 SSE 或公共系统提醒写入“涨停 / 炸板 / 回封”。打板专区的状态事件只写入 `data/user_data/limit_board/events.jsonl`，用于该工作区内部展示。

如需监控涨停、炸板或封单变化，应在监控中心创建 `market` 或 `ladder` 规则；规则的冷却期、严重级别和通知渠道由监控中心统一控制。

## 其它领域事件

持仓风控等领域服务保留各自的事件文件和专用页面时间线，不属于公共监控中心记录。公共 `/api/alerts` 查询、清空和单条删除接口会过滤这些来源，避免历史数据绕过规则显示在监控中心。

五档轮询接管等运行状态只写服务日志或专用状态接口，不进入公共提醒 SSE，也不写入监控中心触发记录。
