# 主线动量与大成交首板分钟研究

## 数据边界

- 主线行业、候选和日线因子只使用交易日 `D-1` 及以前可见的数据。
- 分钟信号使用闭合分钟 K；成交额单位为元，成交量单位为手，VWAP 按 `成交额 / (成交量 * 100)` 计算。
- 前复权价格用于收益和技术指标，原始价格用于涨跌停判断和模拟成交。
- 当日“日线最高价触及涨停”只用于首板策略的分钟文件读取索引。策略只有在逐分钟最高价实际触板后才允许下单，不能提前看到当日收盘、总成交额或触板时间。
- Tushare 和开盘啦资金数据只做买入日前一交易日的匹配样本分析。数据缺失不会缩小主回测股票池，无历史日期的数据不会参与研究。

## 主线动量

主线快照以申万 PIT 一、二级行业历史为准。每个交易日先用 `D-1` 数据选出最多 30 只候选，再读取候选、当前持仓和中证 500 基准的分钟行情。突破、VWAP 回踩、行业共振和组合模板共用候选、退出、费用、T+1 和持仓约束，只改变入场模型。

研究任务将 `2021-07-30` 至 `2024-12-31` 作为训练期，将 `2025-01-01` 至最新完整交易日作为样本外。参数必须在训练期结束后冻结，账户级收益、基准收益、超额、最大回撤和交易数分别统计，不能用信号平均收益代替账户结果。

## 大成交首板

“大成交首板·上午打板”只接受上午第一次触板时累计成交额至少 10 亿元的沪深非 ST 股票。默认稳健门禁为：上市满 120 日、前 5 个交易日没有涨停收盘、`D-1` 五日跌幅至少 5%、`D-1` 总市值不低于 100 亿元。最多持有 5 只，每只约 18%，股票 T+1，持有到第五个未来交易日的 14:55 退出。

回测在触板分钟按涨停价模拟成交，即使随后炸板也保留成交。该规则用于评估信号收益，不代表真实排队一定成交；实盘接入时必须单独评估委托时间、排队位置、封单变化、撤单和券商回报。

## 运行

顺序运行主线模型：

```bash
cd backend
PYTHONPATH=. .venv/bin/python scripts/run_mainline_momentum_research.py
```

运行大成交首板：

```bash
cd backend
PYTHONPATH=. .venv/bin/python scripts/run_large_amount_first_board_research.py
```

结果写入 `data/free_strategy_runs/<run-id>/result.json`。`research_performance` 保存训练期、样本外和逐年账户统计；主线结果的 `entry_analysis` 另外保存 30 分钟、收盘、次日、3 日和 5 日的信号收益、超额、MFE/MAE 以及 D-1 资金流匹配样本。
